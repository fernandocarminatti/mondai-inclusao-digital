# Portal de Inclusão Digital - Mondaí

Portal acessível e gratuito que ajuda pessoas com baixa alfabetização digital a
usar a internet e acessar serviços públicos online. Projeto da disciplina
**Atividades Extensionistas II** - UNINTER - Escola Superior Politécnica (ESP).

## Estrutura do Projeto

```
mondai-inclusao-digital/
├── index.html                 # Página principal (estrutura HTML)
├── assets/
│   ├── css/
│   │   └── style.css          # Estilos do portal
│   └── js/
│       └── app.js             # Interatividade + busca (jQuery)
```

## Como rodar localmente

Não precisa de instalação nem servidor:

1. Dê dois cliques em `index.html` (ou arraste para o navegador).
2. Opcional: um servidor HTTP local pode ser usado.

## Tecnologias

- HTML5 + CSS3 (folha de estilos própria em `assets/css/style.css`)
- [jQuery](https://jquery.com) (CDN)

## Como contribuir
